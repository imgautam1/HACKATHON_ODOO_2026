# CoreInventory – Inventory Management System

CoreInventory is a basic web-based Inventory Management System developed using PHP and MySQL. The system enables users to handle their products, warehouses, stock movements, and delivery operations in one place. The system includes basic inventory management features like product management, incoming stock entries, delivery orders, internal transfer orders, and stock adjustments. The system also includes activity tracking, reporting, and an overview of all the inventory management activities.

This project is developed for learning and understanding how an inventory system and warehouse management work in web-based projects.

# Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP (Apache & MySQL)

# Main Features

- User Login and Signup  
- Inventory Dashboard  
- Product Management  
- Warehouse Management  
- Incoming Stock (Receipts)  
- Delivery Orders  
- Internal Transfers  
- Stock Adjustments  
- Activity Logs  
- Move History Tracking  
- Basic Reports

# How to Run

1. Install **XAMPP**  
2. Move the project folder to **htdocs**  
3. Import the provided **SQL database**  
4. Start **Apache and MySQL**  
5. Open in browser
